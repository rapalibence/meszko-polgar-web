# Mészkő Polgár Kft. — weboldal

Dark, single-page B2B site with a procedural 3D terraced pit (React Three Fiber) that the visitor descends through on scroll.

- Stack: Vite · React 19 · TypeScript · Tailwind v4 · framer-motion · GSAP ScrollTrigger · three / @react-three/fiber · zustand · zod · react-hook-form
- Spec: `docs/superpowers/specs/2026-11-02-meszko-polgar-website-design.md`
- Plan: `docs/superpowers/plans/2026-11-02-meszko-polgar-website.md`

## Scripts

```
npm run dev        # local dev server
npm run build      # type-check + production build (dist/)
npm test           # vitest unit tests (terrain, contours, content, schema, api)
npm run test:e2e   # playwright (builds + previews on :4173, or BASE_URL=https://… against a deployment)
npm run lint
```

## Content

All copy lives in `src/content/*.ts`. Bracketed strings (`[…]`) are placeholders awaiting the client. Product/section images in `public/img` are procedural placeholders generated by `scripts/gen-placeholders.py`; swap for real photos (WebP, plus a `-sm` half-size variant).

## Quote form

`api/quote.ts` validates with `src/lib/quoteSchema.ts` and currently logs. TODO: deliver via Resend (`RESEND_API_KEY`).

## Deploy

Vercel, framework Vite, output `dist/`. SPA rewrite and `/api/*` in `vercel.json`.
