# v4 „Rétegek” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the frame-sequence/3D visual layer with a flat, layered SVG poster world animated only via GSAP transforms/opacity.

**Architecture:** One `PitPoster` SVG with 6 `data-layer` groups is the hero; a GSAP intro timeline plays on load and a ScrollTrigger parallax drives the layers on scroll. `Descent` becomes a GSAP-pinned section with a stroke-drawn progress line. A small `src/lib/gsap.ts` owns registration, reduced-motion matchMedia and a batch reveal helper. framer-motion, three, frames and render tooling are removed.

**Tech Stack:** Vite 8, React 19, TS strict, Tailwind v4, gsap 3 (+ScrollTrigger), vitest, Playwright 1.63.

**Spec:** `docs/superpowers/specs/2026-11-02-v4-retegek-design.md`

## Global Constraints
- Only `transform` and `opacity` animate. No canvas/WebGL/image sequences.
- Palette exactly as spec: bg #F3EADB, sand #E9D8B4, sand-deep #CDB58A, rust #D9521A, rust-deep #A83E12, sky #1F3A5F, sky-deep #14283F, stone #8C867A, ink #15130F.
- Hungarian copy unchanged; no em/en dashes; one CTA label „Ajánlatkérés”.
- `prefers-reduced-motion`: no animation, final states shown.
- Hover effects gated by `@media (hover:hover) and (pointer:fine)`.

## Review Focus
1. Very short landscape viewports (844×390): pinned Descent must not clip the card — Task 4 test at 844×390.
2. Resize/orientation change mid-page: ScrollTrigger must refresh (`ScrollTrigger.refresh()` on resize debounce) — Task 2.
3. Hash navigation to `#folyamat` with pin: landing must show step 1 — Task 4 test.
4. Keyboard focus into pinned section controls: none exist (cards are not interactive) — confirm in a11y test.
5. Page reload mid-scroll: intro must not replay over already-scrolled hero (check `scrollY > 40` → skip intro) — Task 3.
