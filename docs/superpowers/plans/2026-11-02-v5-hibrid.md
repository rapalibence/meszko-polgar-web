> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the site as a photo-led editorial page (Bumi structure, Halo character) with GPU-only GSAP motion.

**Architecture:** Same Vite/React/Tailwind/GSAP stack; `src/lib/gsap.ts` unchanged. New components `Stats`, `Fractions`, `Process`, `CtaBand`, `Contours`; `Hero`, `Services`, `About`, `Footer` restyled. PitPoster/Descent removed.

**Tech Stack:** Vite 8, React 19, TS, Tailwind v4, gsap 3, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-02-v5-hibrid-design.md`

## Global Constraints
- transform/opacity only; `stroke-dashoffset` allowed for line drawing.
- Palette from spec. One accent per screen. Hungarian copy unchanged.
- Hero photo `<img fetchpriority="high" decoding="async">`, srcSet lg/sm.

## Review Focus
1. Hero photo on 2560×1440 must still cover (object-cover, scale origin center) — hero e2e at 2560.
2. Process sticky column must not overlap footer on short viewports — process e2e at 844×390 checks contour svg bottom ≤ viewport.
3. Specimen masks must not clip the photo away entirely on narrow widths — fractions e2e asserts each `img` visible area > 60% of its box at 390.
4. Stats counters with bracket placeholders `[200 000]` must render verbatim (non-numeric) — unit test on CountUp numeric=null path (existing content test).
5. Reload mid-page: no intro replay (existing hero test retained).
